# 🔐 Face Authentication System

A real-time face recognition and verification system using FaceNet, MTCNN, and FAISS.

## 🚀 Features
- Face Detection (MTCNN)
- Face Embeddings (FaceNet)
- Recognition & Verification
- FAISS-based similarity search
- Real-time webcam verification
- Logging & dashboard

## 🧠 Tech Stack
- Python
- OpenCV
- Streamlit
- FAISS
- Keras FaceNet
- MTCNN

## ⚡ Run

```bash
pip install -r requirements.txt
streamlit run app.py
